# Dossier minimo condivisibile

Schema informativo suggerito, non formato imposto né sistema di persistenza. Non copiare dati riservati senza autorizzazione.

| Campo | Significato |
| --- | --- |
| `opportunity_id` | Identificativo ufficiale, ove presente |
| `authority` | Autorità e soggetto gestore |
| `instrument_types` | Una o più categorie: GRANT, LOAN, GUARANTEE, EQUITY, INCUBATION, INTERNATIONALIZATION |
| `jurisdiction` | UE, Stato, Regione, territorio applicabile |
| `official_sources` | URL documento, sezione, versione, data di accesso |
| `status_as_of` | Stato documentato alla data della verifica |
| `applicant_profile` | Attributi forniti dall'utente strettamente necessari |
| `eligibility_matrix` | Condizione, prova, fonte, stato, termine |
| `economic_assumptions` | Importi, date, costi, tassi e ipotesi esplicite |
| `open_questions` | Dati non verificati o documenti necessari |

Per trasferire informazioni a `eu-funding-skills`, riportare le fonti originali e i dati del dossier senza trasformare classificazioni preliminari in requisiti verificati. Non esiste integrazione automatica.
